# مراکز درمانی نزدیک من

نسخه اولیه وب‌اپلیکیشن یافتن بیمارستان‌ها و درمانگاه‌های اطراف کاربر.

## پیش‌نیازها
- Node.js نسخه 20 یا جدیدتر
- npm
- اتصال اینترنت

## نصب و اجرا در ویندوز

```powershell
# وارد پوشه پروژه شوید
cd medical-center-finder

# نصب وابستگی‌ها
npm install

# اجرای محیط توسعه
npm run dev
```

سپس آدرس زیر را باز کنید:

http://localhost:3000

## تست GPS با گوشی
دسترسی Geolocation در مرورگر به HTTPS نیاز دارد (به‌جز localhost).
برای تست روی گوشی، پروژه را روی یک دامنه HTTPS یا محیط تست دارای HTTPS منتشر کنید.
باز کردن سایت با آدرس HTTP شبکه محلی معمولاً اجازه GPS نمی‌دهد.

## قابلیت‌ها
- درخواست خودکار اجازه موقعیت از مرورگر هنگام ورود به صفحه
- استفاده از موقعیت واقعی در موبایل و دسکتاپ پس از تأیید دسترسی
- در صورت رد مجوز، خطا، پایان مهلت یا نبود قابلیت موقعیت‌یابی: استفاده از میدان آزادی تهران و نمایش پیام مشخص
- نمایش فوری ۶ مرکز واقعی ذخیره‌شده اطراف میدان آزادی، پیش از پاسخ موقعیت‌یابی و سرویس آنلاین
- فونت محلی وزیرمتن برای تمام صفحه و نقشه
- جستجوی بیمارستان و درمانگاه با Overpass API
- فیلتر allow-list برای amenity=hospital/clinic و healthcare=hospital/clinic
- نقشه Leaflet و OpenStreetMap
- مسیر رانندگی داخلی با OSRM از دکمه هر مرکز و پنجره روی نقشه
- باز کردن Google Maps برای مسیریابی خارجی
- نمایش مراکز از نزدیک‌ترین فاصله با شعاع پیش‌فرض ۱۰ کیلومتر و امکان کاهش آن تا ۱ کیلومتر

## تنظیم سرویس‌ها
فایل `.env.example` را در صورت نیاز به `.env.local` کپی کنید.
مقادیر پیش‌فرض از سرویس‌های عمومی استفاده می‌کنند:

- Overpass: https://overpass-api.de/api/interpreter
- OSRM: https://router.project-osrm.org

این endpointهای عمومی برای نمونه اولیه هستند و SLA یا ظرفیت تضمین‌شده برای استفاده تجاری ندارند.
برای انتشار عملیاتی، سرویس میزبانی‌شده یا اختصاصی تهیه کنید و شرایط استفاده را رعایت کنید.

## نکات مهم
- میدان آزادی تهران (35.6997, 51.3370) مبنای نمایش اولیه است؛ با دریافت موقعیت، نتایج بر اساس محل واقعی کاربر به‌روزرسانی می‌شوند.
- اطلاعات OpenStreetMap ممکن است ناقص یا قدیمی باشد.
- این ابزار وضعیت باز بودن، پذیرش بیمار یا خدمات اورژانس را تأیید نمی‌کند.
- آدرس و تلفن فقط در صورتی نمایش داده می‌شوند که در داده‌های OSM ثبت شده باشند.
- مسیر OSRM در این نسخه رانندگی است.

## داده اولیه و قطعی سرویس

API ابتدا سرویس عمومی Overpass و سپس سرویس جایگزین `overpass.private.coffee` را امتحان می‌کند. خطای اتصال، محدودیت درخواست و پاسخ ناقص با «نتیجه خالی» اشتباه گرفته نمی‌شوند. در صورت قطعی سرویس، فقط مراکز ذخیره‌شده‌ای که واقعاً در شعاع درخواست هستند برگردانده می‌شوند؛ بیرون از محدوده پوشش داده ذخیره‌شده، خطای واضح نمایش داده می‌شود.

`data/default-centers.json` یک فهرست محدود از داده واقعی OpenStreetMap با مجوز ODbL است؛ فهرست جامع مراکز تهران نیست. شناسه، منبع و زمان دریافت در فایل ثبت شده‌اند. به‌روزرسانی از API اصلی OpenStreetMap:

```powershell
node scripts/update-default-centers.mjs
npm test
npm run build
```

فونت وزیرمتن در `public/fonts` با مجوز SIL OFL همراه پروژه قرار دارد.
